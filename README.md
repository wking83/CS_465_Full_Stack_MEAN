In this project I created two separate and different front-end systems. The first was Express HTML/JavaScript and then a single-page application (SPA) that utilized Angular. Express HTML was created for the public facing part of the application. This portion made is possible for users to see trip information in a server rendered format. SPA systems were created for the administrative interface.  This made more use of a more dynamic user interaction. Some of the developments included client-side routing and reusable UI components. 

The utilization of Angular on the admin side allows for a faster dynamic interaction when it comes to form validation and feedback. This can all be done without full page reloads. Angular also adds modularity through components and routing modules. This enables greater maintainability and upgradability. 

For the backend I used NoSQL MongoDB because it is an excellent choice for semi-structured data. MongoDB is document oriented, which makes it excellent to store objects like trips, users and bookings. This allows fast iteration while communicating with JSON-based frontend requests. 

JSON differs from Javascript because it’s a data-interchange format and not a programming language. It uses a lightweight data structure that is easily transmitted from front end and backend architecture. JSON was used in this program to send requests between Angular and Express API. 

I refactored many components to make them modular by design. This makes the program easier to scale and maintain. Some examples in my code are TripList, TripForm, and TripDetail. This allows us to reduce repetition and improve readability. 

For Testing I used Postman to validate multiple API endpoints using GET, POST, DELETE, and PUT functions. The last challenge I added was the JSON Web Token for authentication.
